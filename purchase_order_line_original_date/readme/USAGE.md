1.  Create a new PO and assign an expected arrival to its lines.
2.  Confirm the PO.
3.  Change the expected arrival of some lines.
4.  Original expected arrival is kept unchanged.

The original expected arrival is set when the PO is approved (directly
at confirmation, or later when double validation applies). It is not
changed when the PO is confirmed again. A line added to a confirmed PO
gets its own original expected arrival.
